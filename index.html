RouterMAS: watermarking a multi-agent router inside the freedom its task values leave open 把水印写进多智能体路由器中任务价值没有锁定的自由度

Fixing what a system must achieve does not fix how it delegates. Bellman recursion turns prefix-wise preservation of task utility and agent-call cost into local conservation equations; a secret key moves routing probability only inside the space they leave open, and the same marked law yields a sequential likelihood-ratio verifier. No agent is retrained. No route is forced. 锁定系统必须达成的价值，并不等于锁定它如何委派任务。Bellman 递推把"每个执行前缀上的任务效用与调用成本都保持不变"化为局部守恒方程；密钥只在这些方程留出的空间里移动路由概率，而同一个带水印的路由法则直接给出序贯似然比验证器。不重训任何 agent，不强制任何路径。

The problem问题

Carrier-first marks pay for it downstream先选载体的水印，代价落在后续执行上

Two systems built from the same models can embody different orchestration policies, so the router is an asset worth attributing. But a delegation is also a functional decision: it changes the history on which every later choice, retry and cost depends. Transferring existing carriers to a multi-agent router assumes a secret preference can be fixed before asking whether the task values permit it: 同一组模型可以组成编排策略完全不同的系统，因此路由器本身就是值得溯源的资产。但一次委派同时也是功能性决策：它改变了之后所有选择、重试与成本所依赖的历史。把现有水印载体直接搬到多智能体路由器上，隐含的假设是：可以先固定一个秘密偏好，再去问任务价值是否允许它：

① Red/green delegation bias红/绿委派偏置

Blind to the future看不到未来

Tilting delegations toward a keyed set ignores what each delegation enables later, so continuation utility and cost drift.把委派往密钥集合倾斜，却不看每次委派之后会引出什么，后续效用与成本随之漂移。

② Behavioral marks行为水印

Averages hide prefixes平均值掩盖前缀

Preserving aggregate utility lets gains on easy prefixes pay for losses on hard ones; prefix-wise continuation values are not part of the contract.只保持总体效用，简单前缀上的收益可以抵消困难前缀上的损失；逐前缀的后续价值不在约束之内。

③ Forced secret paths强制秘密路径

Identifiable for the wrong reason可识别，但原因不对

A fixed route through agents or experts is detectable precisely because it sends work where the original system would not.穿过 agent 或专家的固定路线之所以能被检测，恰恰是因为它把工作派到了原系统不会去的地方。

— RouterMAS

Constraints first, then the key先求约束，再放密钥

Derive the admissible routing changes from continuation values, encode the key only there, and return the original router when none remain.先由后续价值推出可行的路由变化，只在其中编码密钥；没有可用方向时原样返回路由器。

Core question. Which multi-agent routing variations preserve the continuation values a deployment must keep, and how can they carry a verifiable signature with controlled intervention and estimation cost? 核心问题：哪些多智能体路由变化能保持部署必须守住的后续价值？它们又如何在可控的干预与估计代价下携带可验证的签名？
Method方法

Find the freedom, move minimally, verify with the same law找到自由度，最小改动，用同一法则验证

Constituent agents, tools and the executor stay frozen. At each history h the router has a legal delegation set and a reference law ph; for each protected return j (task success, remaining agent-call cost) Qjp(h,a) is the expected return after delegating to a and then following p. The contract is Vjq(h) = Vjp(h) at every admissible prefix. 各 agent、工具与执行器全部冻结。在每个历史 h，路由器有合法委派集合与参考法则 ph；对每个受保护回报 j（任务成功、剩余调用成本），Qjp(h,a) 表示先委派给 a、此后沿用 p 的期望回报。约束是：在每个可行前缀上 Vjq(h) = Vjp(h)。

1

Continuation conservation后续价值守恒

Audit every legal delegation by complete counterfactual continuations under the unchanged reference router. Prefix-wise preservation holds iff (qh−ph)⊤Qjp(h)=0 at every history, leaving a local family of dimension |𝒜h| − rank Bh.在参考路由器不变的前提下，用完整的反事实后续执行审计每个合法委派。逐前缀保持成立当且仅当每个历史上 (qh−ph)⊤Qjp(h)=0，剩下维数为 |𝒜h| − rank Bh 的局部可行族。

where the freedom is自由度在哪里
2

Least-change keyed encoding最小改动的密钥编码

Inside that family, pick the law with the smallest relative entropy to p for its key-score gain: an information projection whose solution is an exponential tilt. Estimation and solver errors are charged to a local budget and shrink the update toward p.在可行族内，选出达到同样密钥得分增益、且与 p 相对熵最小的法则：这是信息投影，解为指数倾斜。估计误差与求解误差计入局部预算，把更新向 p 收缩。

how far to move挪动多少
3

Sequential verification序贯验证

A verifier rebuilds p and qK from frozen snapshots and sums log qK(a)/p(a) over observed delegations. Under the reference null this is a nonnegative martingale, so Ville's inequality caps the false-positive rate at α for any stopping time.验证者从冻结快照重建 p 与 qK，对观测到的委派累加 log qK(a)/p(a)。在参考零假设下这是非负鞅，由 Ville 不等式，任意停时下误报率都不超过 α。

how to prove it如何证明
Vjq(h) = Vjp(h)  ∀h  ⇔  (qh − ph)⊤Qjp(h) = 0  ∀h

Routing moves, values do not, evidence accumulates路由在变，价值不变，证据在累积

A multi-agent routing system with known transitions: four delegation steps, five states per step, six legal delegations, two protected returns, exact backward dynamic programming and η = 1.5. Known dynamics isolate the mechanism from estimation error. 一个转移已知的多智能体路由系统：四步委派、每步五个状态、六个合法委派、两个受保护回报，用精确反向动态规划求值，η = 1.5。已知动力学把机制本身与估计误差分开。
